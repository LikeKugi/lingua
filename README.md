# Лингва — AI Error Explainer

Мобильное приложение для разбора ошибок в языковых заданиях. Оно отправляет вариант пользователя, правильный ответ и исходное задание в OpenAI-совместимый чат API, а затем сохраняет объяснение в локальную историю.

## Запуск в Expo Go

```sh
npm install
npm start
```

Откройте QR-код через Expo Go на телефоне. Для отдельной нативной сборки используйте `npm run android` или `npm run ios`.

## Возможности

- Разбор задания из набора слов или исходного предложения.
- Запрос к OpenAI-совместимому `/chat/completions` API и загрузка моделей из `/models`.
- API-ключ хранится в системном Keychain/Keystore через Expo SecureStore.
- Настройки, промпты и история сохраняются локально в AsyncStorage.
- Редактируемая системная инструкция и библиотека включаемых промптов.
- История с подробным просмотром и удалением отдельных записей или всей истории.
- Ответы модели отображаются с форматированием Markdown.

Сначала сохраните API-ключ в «Настройках», загрузите модели и выберите одну. Там же можно задать язык ответа и дополнительную инструкцию.
